# Per-Thread Stub Backlog Drop-In Directory

Every parallel toolkit thread that encounters an unimplemented Windows API or
subsystem that cannot be implemented in the current round should drop a small
markdown file in this directory (`docs/stub-backlog.d/<topic>.md`).

`docs/stub-backlog.md` is the master index generated by:

```sh
cargo opsdb -- stub-backlog --write
```

## Recommended File Format

```markdown
# <Thread / Subsystem Name>

| DLL!API | Kind | Why Not Implemented Yet | Next Step |
|---|---|---|---|
| `kernel32.dll!SomeApi` | `unimplemented` | Needs macOS kernel primitive / out of scope for this PR | Implement via ... and add zig-cc guest test |
```

Remember: **never add new `stub!()`, `failing!()`, or `win64_stubs!()` call sites**
in `crates/` — document remaining gaps here instead so `cargo opsdb -- doctor`
and `audit_repo_hygiene.sh` stay green.
